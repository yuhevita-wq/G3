# G3 競輪データ作業リポジトリ

このリポジトリをG3過去データ研究の独立した作業場所とする。

## データの原本

- 元リポジトリ: [`yuhevita-wq/keirin-market-analysis-`](https://github.com/yuhevita-wq/keirin-market-analysis-)
- 原本フォルダ: `data/grade_races/g3/`
- 対象: 2022年〜2025年（各Q1〜Q4）、2026年上半期（Q1・Q2）。全18 ZIP。
- 元データの改変は禁止。ガールズ除外表記を含め、原本の分類・欠損を保持する。

取り込みの前に実際のZIP内部構造を監査し、確定した列定義に沿ってデータを整形する。

## 運用原則

- 原本と整形済みデータを区別し、由来とSHA-256を記録する。
- データの欠損を推測で補完しない。
- 出走表／オッズ／結果は時点を分離する。
- 同一レースの重複を監査する。
- 検証期間への結果混入（リーク）を防ぐ。

現在の段階: データ原本の内容を調査して取り込みパイプラインを構築中。
