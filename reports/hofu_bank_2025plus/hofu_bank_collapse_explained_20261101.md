# 防府333m：ラインが「異常に崩れる」構造の深掘り（2025年以降）

調査日: **2026-11-01**。当日開催G3・2日目の結果は一切参照しない。過去の具体例は**2025年1月以降**の結果に限定。

## 1. 結論と必須データ制約

- **2025年度は防府記念G3が非開催**。防府公式2026-10-30記事は「昨年度はウィナーズカップGⅡ開催のため防府記念は非開催、2年ぶりの防府GⅢ」と明示。2025年1月〜2026年6月のG3アーカイブには防府のG3男子S級9車レースが**0件**。2026年10月31日〜11月3日の現開催はデータ未収録。よって2025年以降の保存済みG3データから「防府G3が異常に荒れる」「防府G3二日目にラインが何％崩れる」は検証できない。
- このファイルでは**防府バンクにおける2025年以降のG2/F1/F2等の実例**と**現在に近い防府の男女別決まり手集計**を確認し、他場の2025年以降のG3結果は**対照群のみ**として別扱いにする。
- 「崩れ」の意味は少なくとも①番手の後退（ハコ3）、②ライン3番手の位置奪取、③他ラインの捲り・中割りで上位入替、④ABC（1〜3着3ライン）に分ける。これらは発生因果・車券高配当の発生と同義ではない。

## 2. 防府公式バンク構造・専門機関記述

- 333m / みなし直線42.5m / 最大カント34°41′09″、ホーム幅10.2m、バック幅9.1m、センター幅7.4m。
- 2024年10月再開の改修走路は軽くクセが少なく、捲りが打ちやすい。2センター以降、中バンクが伸びるため捲り追込みが有効。
- 防府競輪場公式は**西風時に向かい風の影響**を指摘。日刊プロスポーツ新聞社のバンク解説は**4角・1角のスタンド撤去で風が入りやすい**、「差し脚のない番手はハコ3も目立つ」「イン粘りが効果的」と説明。
- 直線42.5mは400mバンクほど長くない一方、333mの他場と比べれば短くない。先行有利と番手差し・捲りの双方が成立する。
- したがって「33バンクなら無条件に逃げ・番手・3番手のワンツースリー」とはしない。風向き・自力選手の仕掛け位置・外の加速力・番手の反応が重要。

## 3. 防府における2025年以降の実際の崩れ方

### ケースA：番手は絶好でも「ハコ3」、別ラインが2着

- **2025-03-26 防府F1・2日目1R（A級一般・7車）**。並び予想 **⑦三木健正→①高嶋一朗→⑤川上修平**（他に別ライン選手）。
- 実際の結果 **⑦三木1着（逃）→③野村2着（捲）→①高嶋3着**。3連単 **7-3-1、1,430円**。
- 競走結果の勝敗因には①高嶋について**「絶好ハコ３」**と明記。①が⑦の番手にいながら、別ライン③に交わされ3着に後退した直接的証拠。
- なお1,430円の低額配当。**筋が崩れたことと「大穴」は別**である。
- 出典 https://keirin.kdreams.jp/hofu/racedetail/6320250325020001/

### ケースB：別ラインに3番手を奪われたライン分断

- **2026-03-20 防府G2ウィナーズカップ・2日目7R（S級二予選・9車）**。
- 予想ライン **②石原颯→④河端朋之→⑧桑原大志**。
- 防府公式は「打鐘から仕掛けた中四国ラインの3番手を北日本2車ラインに奪われた」と記録。その結果、⑧桑原は**6着**。
- 確定決着 **④河端1着（差）→②石原2着（逃）→⑦新田3着**。3連単 **4-2-7、4,250円**。
- これもライン2人は残るが3番手が崩れて別線が3着に飛び込んだ例。配当は5万円以上の大穴ではない。
- 出典：公式 https://www.hofukeirin.jp/blog/20260320/ ; 結果 https://keirin.netkeiba.com/race/result/?race_id=202603206307

### ケースC：強烈な捲りで上位3名が別ライン、先行の中心は9着

- **2026-03-22 防府G2ウィナーズカップ・決勝12R（S級・9車）**。
- 当日の主なライン構成：南関 **⑨深谷知広→⑤小原太樹**、関東 **③吉田拓矢→⑦眞杉匠**、中四国 **①清水裕友→⑥久米康平**、単騎②古性・④菅田・⑧山崎。
- 2コーナーから⑨深谷が捲って、確定 **⑨深谷1着（捲）→⑦眞杉2着→①清水3着**。3連単 **9-7-1、53,150円（160番人気）**。
- ⑨の番手⑤は6着、関東ライン先頭③は9着。勝者のラインの番手が上位3に残らない、**ABC・三者別ライン**の高配当例。
- レース分析は深谷の捲りと位置取り・主導権争いを記述。結果だけで「⑤がどの地点で千切れたか」は断言しない。
- 出典 https://keirin.kdreams.jp/hofu/racedetail/6320260319040012/ ; https://keirin-web.com/commentary-analysis/secret/7227/ ; https://www.aokei-stadium.com/keirin/results/63/2026-03-22/

### 対照：普通に番手差しで決着する展開もある

- **2026-03-20 防府G2・2日目8R**。③? ではなく先行は**①町田太我**、番手 **⑨清水裕友**。防府公式は町田が1周半先行し清水が差して**1着**と説明。
- 「防府＝必ず番手が崩れる」という言い方は誤り。強い先行ラインの番手差しも普通に発生する。
- 出典 https://www.hofukeirin.jp/blog/20260320/

## 6. 本日の防府G3 1Rへの含意（未検証の展開仮説）

今日の想定ライン **③長田→⑨小松崎→④開坂**、**⑤平尾→⑦山口→①合志**、単騎②坂本・⑥佐野・⑧奥村。

| 崩れパターン | 展開仮説 | 参考となる並びの決着形 |
|---|---|---|
| **ハコ3** | 先行③を⑨が差し切れず、別線が2着に介入 | **3-7-9** (ABA) |
| **3番手脱落** | 東ライン③⑨は残って④が外れ、別線または単騎が3着 | **9-3-7** / **9-3-2** (AAB) |
| **九州番手の浮上** | ⑤平尾を⑦山口が交わす／他の自力を捌く | **7-5-9** (AAB) |
| **捲りによる総崩れ** | 東・九州・単騎から各1車上位 | **9-7-2** (ABC) |
| **東ライン完全維持** | 3車が決着する「崩れない」対照 | **9-3-4** (AAA) |

- すべて予想上の着順シナリオであり、実際の2026-11-01の結果ではない。
- 防府でABCが多発するという場別比率は、現時点の2025+データでは未検証。
- 日次の風向風速・路面状態・位置取り・前日からの体力負担を加えないと、直線の伸びと千切れリスクを現在のレースで定量化できない。
